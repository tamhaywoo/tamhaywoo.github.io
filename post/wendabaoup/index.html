文大宝高中三年关键时间节点

2026-07-05 • 16 分钟阅读 • 教育相关

高中学习目标：

  • 保持在雅礼班或雅礼强基班
  • 保持在班级前五名
  • 积极参与班级管理
  • 积极参与综合素养活动

大学报考目标：

  • 清华大学、北京大学、中国科学技术大学
  • 复旦大学、厦门大学、上海交通大学
  • 南开大学、浙江大学、华中科技大学

高一（2026年8月 — 2027年7月）

关键词：适应、选科、首轮学考

2026年8月20日左右 · 报到 + 入学考试 + 军训

报到材料清单

  • 录取通知书（必须原件）
  • 户口本原件 + 复印件（户主页+学生本人页，各3份）
  • 身份证原件 + 复印件（3份）
  • 一寸证件照（蓝底/白底各10张，电子版也存好）
  • 学费15800元/学期 + 住宿费1600元/学期（如住宿）+ 校服费396元/套

入学考试

  • 怡海依托雅礼教研体系，考试难度可能高于普通学校
  • 考试科目预计：语文、数学、英语、物理、化学（以中考范围为主，可能含拔高题）
  • 成绩影响分班，认真对待，但也不用过度紧张
  • 考前一天保证睡眠，不要突击

军训

  • 长沙8月下旬高温，持续约1-2周
  • 物理准备：防晒霜SPF50+（面部+身体各一瓶）、大容量水杯（1.5L以上）、透气运动鞋（别穿新鞋）、藿香正气水、创可贴、润喉糖
  • 身体准备：从现在开始每天适当运动，避免突然高强度军训导致中暑或拉伤
  • 注意：如遇生理期，提前准备并向教官说明

住宿安排

  • 怡海宿舍8人间，配空调、24小时热水、洗衣机、暖气
  • 床上用品：提前确认学校是否统一采购（一般会统一，如不统一需自备）
  • 自备：洗漱用品、毛巾多条、拖鞋（宿舍+浴室各一双）、衣架、水杯、雨伞
  • 常用药：感冒药、肠胃药、创可贴、藿香正气水、布洛芬
  • 全封闭管理，手机大概率被统一管理，提前做好心理准备

入学后立刻做的事

  • 加班主任微信/家长群
  • 确认学校网站/公众号关注（通知渠道）
  • 记下教务处、宿管、班主任电话

2026年9月 · 开学适应期

学业适应

  • 9门课全开：语数英+理化生+政史地
  • 高中知识量是初中的2-3倍，最大的坎在数学（集合、函数、不等式）和物理（运动学、力学、矢量思维）
  • 建立高中学习闭环：预习15min → 课堂笔记 → 当天复习 → 作业 → 错题本
  • 雅礼体系节奏快、要求高，前2-3周可能跟不上
  • 英语：高中词汇量要求3500+，比初中翻倍，开始每天背20个单词

生活适应

  • 全封闭管理下时间很紧（早读→上午课→午休→下午课→晚自习），尽快适应作息
  • 食堂档口提前踩点，摸清哪些吃的靠谱
  • 同学关系：主动融入，但不强求（高一换班后圈子会重洗）

月底第一次月考

  • 这是高中第一次正式考试，考9门全部科目
  • 成绩不重要（大家都不适应），重要的是发现哪些科目是你的弱项
  • 这次月考成绩是选科的第一个参考数据

2026年10月 · 选科准备期（关键）

国庆假期（约7天）

  • 不建议完全放松，每天保持2-3小时学习状态
  • 重点复习弱科，提前预习10月新内容
  • 可以开始了解选科方向

选科准备工作

需要搞清楚三件事：

要搞清楚的事 怎么查
各科年级排名 看月考+平时测验的相对排名（不只看绝对分数）
3+1+2组合方案 物理/历史二选一 + 化/生/政/地四选二 = 12种
目标大学选科要求 登录湖南省教育考试院官网 → 查《选考科目要求指引》
本校师资优势 问班主任怡海哪些组合老师强、往年赋分好

选科决策参考

  • 学医 → 物+化+生（最优）
  • 工科/计算机 → 物+化+地理 或 物+化+生
  • 法学/新闻 → 历史+政治+地理/生物
  • 经济/管理 → 物理/历史均可，看分数
  • 怡海有雅礼竞赛资源 → 如果孩子有竞赛潜力，物化生组合竞赛通道最全

家长做的事

  • 参加学校选科家长会（一般10月中下旬开）
  • 不要把自己的期望强加给孩子
  • 如果举棋不定，选物理比选历史后续专业选择面宽得多（约95% vs 85%专业覆盖率）

2026年11月 · 期中考试 + 选科定夺

第一次期中考试（约11月上旬）

  • 高中第一次大型考试，各科都考
  • 成绩出来后，重点看各科的年级排名（不是绝对分数）
  • 结合月考+期中两次排名，基本能判断各科在年级中的相对强弱

选科正式决策

  • 怡海一般在高一上学期结束前完成选科登记
  • 选定后不要变动（有的学校允许第一学期末微调一次）
  • 选定后，未选科目虽然还要学到期末，但不计入高考

综评档案首次填写（12月底前上传）

  • 使用EEID账号登录平台：http://zhpj.hnedu.cn
  • 第一学期重点填写思想品德（军训、入团申请）+ 身心健康（军训、校运会）
  • 每个子维度上传≤10条，遴选上报≤5条
  • 注意仔细检查，上报后不能修改。

2026年12月 - 2027年1月 · 期末冲刺

2026年12月

  • 期末复习开始，重点抓弱科
  • 12月底前必须上传综评材料（具体截止时间每学期关注平台通知）
  • 综评必填：思想品德（志愿服务记录）、学业水平（月考成绩+学习表现）、身心健康（锻炼记录）、艺术素养（如有参加校园活动）、社会实践（军训）
  • 照片要求：每张不超过500KB，需要用电脑压缩

2026年1月 · 期末考试

  • 高一上学期最后一次考试
  • 成绩反映了选科前的综合能力，但不计入高考
  • 放寒假前：找班主任要下学期的预习建议

寒假规划（约4周）

  • 第一周：彻底放松，调整状态
  • 第二三周：每天2-3小时，预习高一下内容（重点预习选科科目）
  • 第四周：社会实践（研学/志愿服务），积累综评素材
  • 英语单词每天背，别断

2027年3月 · 学考报名 ⚠️

3月20日-4月2日 · 报名窗口

  • 高一统一报考：历史、化学、地理、生物 4科
  • 学校集体操作网上报名（家长只需确认信息无误）
  • 4月7日前完成缴费，错过缴费窗口视为放弃，只能等下一年
  • 科目确认：确保只报了这4科，不报语文、数学、外语、物理（高二再报）

4月-5月 · 学考复习

  • 4科合格考难度不高（远低于高考），但必须保证全部合格
  • 任何一科不合格 → 影响高中毕业证 → 影响综评/强基
  • 怡海学校会统一组织复习，跟紧学校节奏即可
  • 期末同步复习（语数外+选科3门不能放）

2027年5月底 · 综评第二次上传

  • 检查上学期上传的材料是否审核通过
  • 本学期新增：学考报名记录、学科竞赛参与（如有）、研学旅行记录（如有）
  • 军训材料必须这个学期内上传（此时已过半年，容易忘）

2027年6月 · 学考合格性考试 + 期末

6月12日-14日 · 学考（高一4科）

  • 6月14日（上午）：化学、地理 → 高一参加
  • 6月14日（下午）：历史、生物学 → 高一参加
  • 考试时长：每科60-90分钟
  • 全部为选择题+非选择题，合格线为60分
  • （6月12-13日的语文/物理/数学/思想政治为高二年级考试）

期末考试

  • 学考结束后立即进入期末复习
  • 成绩决定高二分班时在同组合班级中的排名

暑假规划（约8周）

  • 前2周：放松
  • 中间4周：预习高二选科科目（高二知识难度比高一大一个台阶）
  • 后2周：社会实践/研学旅行/志愿服务，集中积累综评素材
  • 英语单词继续，建议开始用高中词汇书系统背诵

高二（2027年9月 — 2028年7月）

关键词：分班、提速、学考清零

2027年9月 · 选科分班

分班

  • 进入选科组合专属班级
  • 新班级新老师新同学，重新适应
  • 教学节奏明显加快，每科每周课时增加
  • 语数英不再按年级统排，而是按组合分班教学
  • 开始接触高考难度题型，期中期末成绩开始有参考价值

开学前准备

  • 预习选科科目高二上内容（重点预习理科：数学的函数与导数、物理的力学进阶等）
  • 复习高一选科科目的基础，别出现断层

2027年10月-11月 · 期中 + 竞赛 + 艺体方向

期中考试

  • 第一次在选科组合班级中的正式排名
  • 检验选科是否正确——如果排名大幅下滑，说明可能选科方向有问题
  • 高二上学期是知识密度最大的阶段，重点抓选科3门

学科竞赛

  • 怡海有雅礼拔尖创新人才培养基地 + 丘成桐少年班资源
  • 如果文大宝在某个学科有突出优势，高二上可以尝试竞赛
  • 常见竞赛时间：
    • 数学竞赛：9月预赛/10月联赛
    • 物理竞赛：9月预赛/10月复赛
    • 化学竞赛：5月初赛/9月决赛
    • 生物竞赛：5月联赛
    • 信息学竞赛：10月初赛/11月复赛
  • 竞赛路线一旦走，会大量占用时间，慎重权衡

艺体方向

  • 如果考虑走艺术/体育高考路线，高二上学期必须决定并开始集训
  • 艺体类培训费高、时间占用大
  • 如果没有这方面想法，直接跳过

2027年12月 · 期末前综评上传

  • 12月底前上传本学期综评材料
  • 本学期重点：学业水平（竞赛获奖、研究性学习报告）、社会实践（寒暑假积累的）
  • 检查前三个学期材料完整性，不要有空白维度

2028年1月 · 期末考试

  • 高二上期末考，知识密度最大阶段的总检验
  • 寒假重点：针对选科弱科集中突破，不要刷九门课

2028年3月 · 学考报名（最后窗口）⚠️

报名对象

  • 高二学生可报全部9门科目
  • 已取得合格成绩的不重复报考
  • 主要是补报高一时未报考的科目：语文、数学、外语、物理、思想政治（5科）
  • 如果高一学考有不合格科目，此次必须补考
  • 仍由学校集体报名，家长确认即可

为什么这是最后窗口

  • 高三不再安排学考
  • 任何一科在此时仍未合格 → 无法获得高中毕业证
  • 影响强基/综评/高校录取
  • 务必确保所有科目全部通过

2028年4月-5月 · 学考复习

  • 5月中下旬学期末综评上传（最后一次正式综评——高三不再有时间）
  • 学考复习跟紧学校安排即可（难度远低于选考科目）

2028年6月中旬 · 学考 + 期末

学考合格性考试（剩余科目）

  • 参考2026年安排：
    • 6月12日上午语文/物理，下午外语
    • 6月13日上午数学/思想政治
    • 6月14日上午化学/地理，下午历史/生物
  • 已通过高一学考的可不参加对应场次

期末考试

  • 高二结束，正式进入准高三状态

2028年7月-8月 · 暑假（最关键的一个暑假）

这个暑假不能大休

  • 怡海高三大概率8月初就开学（雅礼系通常提前开学）
  • 暑假有效时间只有4-5周

必须做的事

  1. 系统复习高一高二选科科目的全部知识点（买高考一轮复习资料）
  2. 数学：函数与导数、解析几何、概率统计（三大板块必须过一遍）
  3. 英语：背完高考3500词（如还没背完）
  4. 错题本整理：把高二所有大考错题整理成册

证件检查

  • 身份证是否2029年9月30日之后到期？（高考报名需要有效身份证）

高三（2028年9月 — 2029年7月）

关键词：高考报名、强基综评、决战6月

2028年9月 · 一轮复习启动

复习规划

  • 各科开始地毯式一轮复习，覆盖高一高二全部知识点
  • 跟紧老师节奏是第一要务，不要自己另外搞一套
  • 每周做一套完整的模拟卷（限时），培养考试节奏

检查事项

  • 综评档案最后一次检查：高一高二四个学期材料是否齐全、审核是否通过
  • 检查孩子身份证：是否在2029年9月30日前过期？过期的话立即去派出所补办（高考报名需要）
  • 确认户口本和身份证地址一致（不一致需去派出所更新）

高三上学期心态

  • 刚开始一轮复习会觉得"好像什么都不会"，这是正常的
  • 一轮复习是捡回来的过程，不要焦虑

2028年10月 · 高考报名 🔴（全年最重要的事，没有之一）

时间：10月16日-31日（仅工作日，周末不办理）

为什么重要

  • 这是高考报名的唯一窗口，过期不补，不设补报名
  • 错过这个窗口 = 无法参加2029年高考 = 等一年
  • 每年都有家长犯这个错误

报名方式

  • 平台：
    • 潇湘高考APP（手机端）
    • 湖南省考生综合信息平台（电脑端 hneeb.cn）
  • 学校会统一组织，但家长和学生必须亲自确认信息无误

报名需要准备的材料

  • 身份证（在有效期内，建议办证时间不早于2025年1月）
  • 户口本（确保户籍信息与身份证一致）
  • 学籍信息（学校提供）
  • 近期免冠证件照（电子版，按要求格式）

报名步骤

  1. 注册/登录潇湘高考APP
  2. 填写个人信息（姓名、身份证号、民族、户籍、学籍等）
  3. 上传证件照
  4. 选择报考类别（普通高考/对口招生/高职单招等）
  5. 缴纳报名费
  6. 确认提交 → 打印报名确认表 → 签字

⚠️ 特别重要

  • 身份证报名后到大学报到前，不要修改姓名、照片、性别、民族、出生日期等关键信息
  • 非湖南户籍考生需提前确认是否符合随迁子女报名条件
  • 具有普通高校学籍的学生（如已被大学录取但未报到）不能报名

2028年11月3日-10日 · 艺术类/体育类统考报名缴费

  • 仅适用于走艺体路线的考生
  • 如果文大宝不走艺体，此步跳过
  • 报名缴费也在潇湘高考APP上

2028年11月 · 期中考试（一模性质）

  • 一轮复习进行到一半，期中考试检验复习效果
  • 成绩用于初步定位目标院校层次

2028年12月6日起 · 艺术类统考

  • 音乐类、舞蹈类、表导类、播音主持类、美术与设计类、书法类6科统考
  • 如果文大宝不考艺体，继续一轮复习，此项跳过

2029年1月 · 期末考试/全市一模

  • 一轮复习收尾，第一次完整的全市统一模拟考
  • 成绩对后续复习策略和志愿定位有重要参考

寒假安排

  • 不宜长休，保持学习节奏，二轮复习启动

2029年2月 · 二轮复习

  • 专题突破阶段：按知识点板块刷题，不再是地毯式
  • 开始做近5年高考真题（限时模拟真实考试环境）
  • 错题本持续更新

2029年3月 · 综合评价报名启动

综合评价报名（3月-5月）

  • 部分高校（南科大、上科大、华南理工、港中文深圳等）开始报名

报名材料清单（从高一开始积累）

  • 高中各学期成绩单
  • 学考合格性考试成绩
  • 高三模拟考试（一模/二模）成绩
  • 获奖证书扫描件（教育部白名单赛事为佳）
  • 个人陈述/自荐信（800-1000字，围绕目标专业展开）
  • 推荐信（非必须，但有更好）
  • 综合素质评价档案

报名平台

  • 阳光高考平台（https://gaokao.chsi.com.cn）
  • 一个学校一般可报1-6个专业
  • 注册阳光高考网账号（如果之前没注册）
  • 建议目标院校层级：冲1-2所 + 稳1-2所 + 保1-2所

三月下旬

  • 3月底-4月初通常有二模

2029年4月 · 强基计划报名 ⚠️

时间

  • 4月各高校陆续发布招生简章，发布后随即开始报名

强基计划要点

  • 39所985高校参与，只能报1所
  • 招生专业偏基础学科：数学、物理、化学、生物、历史、哲学、古文字等
  • 录取依据：高考成绩（85%）+ 校测成绩（15%）
  • 录取在所有批次之前，一旦录取不再参加后续志愿

报名流程

  1. 4月简章发布 → 阅读简章（招生专业、入围标准、校测形式）
  2. 在阳光高考平台报名（多数高校不需要额外材料）
  3. 选择一个合适的学校（太高的可能入围不了，太低的浪费机会）

判断标准

  • 强基计划不适合所有人。专业偏基础学科，如果对工科/应用型专业更感兴趣，强基可能不是最优解
  • 适合的画像：某一基础学科特别强 + 对科研有兴趣 + 能接受偏基础的专业
  • 部分高校（复旦、上交、南大等12所）校测在出分前，意味着高考完就得马上去考

综合评价报名继续

  • 多数综评报名在4月底-5月截止

2029年5月 · 三轮复习 + 综评初审 + 综合素质材料上报

三轮复习

  • 回归基础 + 查漏补缺 + 保持状态
  • 不再刷新题，以真题和错题本为主

综评初审公示（5月底）

  • 登录报名系统查看是否入围
  • 入围者需进行考试确认及缴费

综合素质材料上报（5月底前）

  • 强基计划考生各省市组织综合素质评价材料补充填写
  • 学校统一操作，家长确认即可

5月底-6月初 · 考前调整

  • 调整作息，保证睡眠
  • 不再刷难题，以保持手感和信心为主
  • 提前看考场、准备考试用品

考前准备

  • 考试用品：准考证、身份证、2B铅笔（多支削好）、黑色签字笔（多支）、橡皮、无标签矿泉水、透明笔袋
  • 手表：机械表或石英表（禁止电子表）
  • 不要带：手机、电子设备、修正液/修正带
  • 路线踩点：提前确认从住处到考场的路线和时间

考试期间

  • 每科考完不要对答案
  • 保证饮食清淡、充足睡眠

2029年6月中旬 · 强基/综评校测

出分前校测

  • 12所高校（复旦、上交、南大、浙大、中科大、人大、北航、同济、西交大、东南、厦大、兰大）
  • 高考后立即进行，备考时间极短
  • 校测形式：笔试/面试 + 体质测试
  • 笔试难度接近竞赛水平

出分后校测（其余高校）

  • 等6月23-26日出分后，按高考成绩3-6倍确定入围名单

综合评价校测

  • 集中在6月中下旬
  • 多数为面试，部分有笔试和体测

2029年6月23日-26日 · 高考出分

  • 湖南公布高考成绩和分数线
  • 登录湖南省教育考试院网站或潇湘高考APP查分
  • 名次比分数更重要（各校录取看省排名）
  • 准备志愿填报方案（出分前就应该有预案）
  • 强基计划入围名单公布

  2. 综合评价录取（提前批）
  3. 普通批次（平行志愿）

  • 湖南实行"院校专业组"模式，选科决定了能报哪些专业组
  • 注意"冲稳保"梯度安排
  • 服从调剂选项慎重选择（不服从有退档风险）

容易踩的坑

  1. 合格考不当回事 —— 合格考不过拿不到毕业证，也会影响强基/综评材料。高一4科（史化地生）一定要认真准备
  2. 选科拖到高二才定 —— 高一上学期期中后就该定，拖太久会跟不上选科班的进度
  3. 高考报名错过窗口 —— 10月16-31日，只有半个月窗口，逾期绝对不补，这是每年都有家长犯的致命错误
  4. 强基只报不看要求 —— 强基只能报1所，且专业偏基础学科（数理化生文史哲），不是所有孩子都适合，提前了解别盲目报
  5. 综评材料临时准备 —— 综合评价需要高中三年成绩、获奖证书、个人陈述，临时抱佛脚来不及，从高一开始就有意识积累
  6. 忽视综合素质评价档案 —— 这个档案贯穿三年，强基面试会问到档案内容，必须如实填写、认真对待
