文大宝综合素质评价档案积累指南

2026-07-05 • 6 分钟阅读 • 教育相关

湖南省高中综合素质评价平台：http://zhpj.hnedu.cn
登录方式：EEID账号（学校统一注册）

一、综合素质评价档案到底多重要？

湖南高考录取模式是"两依据、一参考"：依据高考成绩和学考成绩，参考的就是这本综合素质评价档案。

三个直接用途

用途 具体影响
强基计划校测面试 高校面试官直接翻档案提问，档案内容影响面试得分
综合评价招生录取 成绩占录取总分比例（通常15%-30%）
同分排序参考 高考同分时，综评档案作为排序依据

一句话总结：高考成绩决定你能进什么档次，综评档案在你进了档次之后决定你能不能比别人先被挑走。

二、平台和操作流程

基本规则

  • 5个维度，每个维度下有11个子维度
  • 每学期每个子维度最多上传10条事实材料
  • 每学期每个子维度最多遴选上报5条进入学期档案
  • 每条材料最多上传2张照片，每张不超过500KB
  • 上报后不能修改不能撤回（所以上报前仔细检查）
  • 超过学校规定的填报时间窗口后无法操作

每学期操作流程

上传材料 → 遴选材料 → 上报材料 → 班主任审核 → 学校管理员审核

⚠️ 关键提醒

  • 每学期都要做，过期不补
  • 每学期截止时间一般为：上学期12月底、下学期5月底（具体以平台通知为准）
  • 高三上学期（10月底前）为最后一次正式上传窗口

三、五大维度怎么积累

1. 思想品德 —— 真实活动，按需积累

可积累项目 怎么操作 证明材料
志愿服务 每学期1-2次社区服务、图书馆义工、养老院探访 活动照片 + 盖章证明/感谢信
环保公益 参加植树、垃圾分类宣传等 现场照片 + 活动说明
党团活动 入团申请、团员会议、主题团日活动 活动记录照 + 文字描述
学校表彰 三好学生、优秀班干部、文明标兵 荣誉证书照片

行动建议：长沙市社区服务中心、公共图书馆定期招义工，直接报名参加就行。关键是要拿到盖章证明，别只拍照了事。

2. 学业水平 —— 含金量最高，重点发力

可积累项目 含金量 怎么操作
教育部白名单赛事获奖 ⭐⭐⭐⭐⭐ 全国中学生奥赛、信息学竞赛、科技创新大赛等
研究性学习报告 ⭐⭐⭐⭐ 选一个课题，写3000字以上报告，附过程照片
学科竞赛获奖 ⭐⭐⭐⭐ 数学/物理/化学/生物/英语等
作文/演讲比赛 ⭐⭐⭐ 校级及以上
发表文章/解题方法 ⭐⭐⭐ 校刊、学科杂志投稿
科技创新/专利 ⭐⭐⭐⭐⭐ 发明创造、实用新型专利

行动建议：

  • 怡海中学有雅礼拔尖创新人才培养基地和丘成桐少年班资源，好好利用
  • 雅礼体系的竞赛资源很强，高一开始就可以关注竞赛方向
  • 研究性学习不用等学校布置，寒暑假自己就能做：定一个课题（比如"长沙市XX交通状况调查"），写一份完整报告

3. 身心健康 —— 门槛最低，坚持就行

可积累项目 怎么操作 证明材料
校运会参赛 报名参加1-2个项目 比赛照片 + 成绩记录
体育特长 篮球/游泳/羽毛球等长期坚持 训练照片 + 获奖证书
日常锻炼记录 每天跑步/跳绳打卡 月度打卡汇总表+照片
心理素质 参加心理健康讲座、应对困难经历 讲座参与记录

行动建议：这个维度最简单，校运会每学期都有，报名就行。如果文大宝有体育特长（比如怡海有游泳特长项目），这是天然的优势材料。

4. 艺术素养 —— 有特长加分，没特长也有办法

可积累项目 怎么操作 证明材料
乐器演奏/歌唱 参加校园艺术节、汇演 演出照片/视频截图
美术/书法 作品参赛或展览 作品照片+参展证明
舞蹈/戏剧 校园文艺活动 排练+演出照片
手工艺/设计 手工制作、海报设计 成品照片

行动建议：如果文大宝没有专门的艺术特长，学校的艺术节、合唱团、黑板报设计都是可积累的素材。重点是 “参加了什么，留下了什么”。

5. 劳动与社会实践 —— 假期集中发力

可积累项目 怎么操作 证明材料
研学旅行 寒暑假组织或参加研学营 行程照 + 研学报告
社会调查 设计问卷、街头采访、数据分析 调查方案 + 照片 + 报告
生产劳动 农田体验、工厂参观、手工制作 劳动照片 + 心得
军训 学校统一组织的军训 军训照片（学校统一拍）
家务劳动 寒暑假家务记录 月度家务清单+照片

行动建议：这个维度主要在寒暑假集中积累。军训是学校统一组织的，自动有材料。研学旅行可以利用家庭出游计划，做成一份研学报告。

四、每学期积累节奏表

学期 学业水平重点 其他维度重点 注意时间
高一上 适应高中，关注竞赛入门 军训记录、志愿服务1-2次 12月底前上传
高一下 学科竞赛参与、研究性学习1 校园活动、春季志愿服务 5月底前上传
高二上 竞赛冲刺、发表文章 校运会、艺术节参与 12月底前上传
高二下 核心竞赛出成果、研究性学习2 研学旅行、社会实践 5月底前上传
高三上 整理已有成果，不再新增 补齐空缺维度 10月底前上传（高考报名前）

高三开始后基本没时间搞这些了，所以高一高二四个学期是主要积累期。

五、三个最容易踩的坑

坑1：觉得不重要，三年后才发现缺材料

档案一旦上报就无法修改，每学期窗口过就关。高一什么都不做，到了高三综评报名时才发现档案是空的——每年都有大量家长犯这个错误。

坑2：造假或者虚构活动

强基面试官会针对档案里的内容追问。“你说做过XX课题研究，能说说你的研究方法和结论吗？"——如果说不出来，直接判负分甚至取消资格。

可以包装但不能造假。

坑3：材料只为凑数，没有主线

五个维度都塞满不等于好档案。好的档案有一条主线——比如文大宝如果对生物/医学感兴趣：

  • 学业水平：生物竞赛 + 研究性学习（医学相关课题）
  • 社会实践：医院志愿服务
  • 思想品德：社区医疗义工
  • 四个维度围绕一个主题，给面试官留下"目标明确"的深刻印象

六、具体操作 checklist（每学期对照执行）

学期初（开学第一个月）

  • 登录 http://zhpj.hnedu.cn 确认账号能正常登录
  • 查看学校发布的本学期填报截止日期
  • 规划本学期重点积累哪个维度

学期中（日常积累）

  • 每次活动后立刻拍照+保存证明（别等学期末再找）
  • 照片先用电脑压缩到500KB以下
  • 简单记录活动内容（时间、地点、做了什么、有什么收获）

学期末（截止前2周）

  • 汇总本学期的所有材料
  • 筛选最有价值的5条材料（精，不是多）
  • 上传 → 检查 → 遴选 → 上报
  • 上报前让家长帮忙过一遍（避免错字/缺材料）
  • 上报后截图保存，记录上传了什么

七、档案类型速查

材料类型 接收格式 大小限制 备注
照片 JPG/PNG ≤500KB/张 每条材料最多2张
证书 拍照或扫描 同照片规则 确保文字清晰可读
证明/感谢信 拍照上传 同照片规则 必须有公章
文字描述 平台内直接填写 — 简洁明了，突出收获
视频 不支持 — 截图关键画面作为照片上传
